SYSTEM BEHAVIOR

A long-running input system, not a staged mockup.

01

Multi-display state

Each display receives an independent HUD; saved widget placement moves safely when a screen disappears.

02

One hold clock

Progress, stage artwork, and key-up selection share one monotonic sample so the picture cannot drift from the action.

03

Input deduplication

Mirrored callbacks from the remote's multiple HID interfaces collapse into one physical state transition.

04

Safe focus following

Focus follows the pointer only for windows that substantially fill a display, avoiding accidental reordering across overlaps.

05

Physical shortcut recording

Layout records real keys, including left/right modifiers, Fn, F1-F20, and modifier-only chords.

06

Install and recovery

A native installer, one live System Check, and visible permission health make the direct-distribution path recoverable.
